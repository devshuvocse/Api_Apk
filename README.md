# App Download Website (GitHub + Vercel Ready)

এই প্রজেক্টটি সরাসরি **GitHub**-এ আপলোড করে **Vercel**-এ হোস্ট করার জন্য তৈরি করা হয়েছে।

## ফাইল স্ট্রাকচার (Project Structure)
```text
├── index.html      # মূল ওয়েবপেজ (Download Now বাটন সহ)
├── style.css       # ডিজাইন এবং রেসপন্সিভ স্টাইল
├── script.js       # বাটন ক্লিক ইন্টারঅ্যাকশন
├── vercel.json     # Vercel ডাউনলোড হেডার কনফিগারেশন
├── app.apk         # আপনার অ্যাপ ফাইল (এটি আপনার আসল অ্যাপ দিয়ে রিপ্লেস করুন)
└── README.md       # গাইডলাইন
```

## কীভাবে ব্যবহার করবেন?
1. এই জিপ ফাইলটি আনজিপ (Extract) করুন।
2. আপনার আসল অ্যাপ্লিকেশন ফাইলটির নাম দিন **`app.apk`** এবং এই ফোল্ডারের ভেতরে থাকা ডেমো `app.apk` ফাইলটির জায়গায় আপনার আসল ফাইলটি রাখুন। *(যদি আপনার ফাইলটি `.exe` বা `.zip` হয়, তবে `index.html` এর ১৯ নম্বর লাইনে `app.apk` এর বদলে আপনার ফাইলের নাম দিন)*।
3. সবগুলো ফাইল আপনার **GitHub Repository**-তে আপলোড করুন।
4. **Vercel.com**-এ গিয়ে **Add New Project** ক্লিক করে আপনার GitHub রিপোজিটরিটি Import করুন এবং **Deploy** বাটনে ক্লিক করুন।
